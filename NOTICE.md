# Notice

This package (Digital Cement Passport – illustrative pilot implementation) is an adaptation, to cement,
of the modelling approach of:

* **Battery Pass data model** – Battery Pass consortium, https://github.com/batterypass/BatteryPassDataModel,
  release 1.2.0. The repository README states that the work is made available under the Creative Commons
  Attribution 4.0 International license (CC BY 4.0), https://creativecommons.org/licenses/by/4.0/.
  Some model files in that repository still carry an older CC BY-NC 4.0 header; no files or text from the
  repository are included in this package.

Changes made: the battery aspects (e.g. carbon footprint per lifecycle stage, circularity, material
composition) were replaced by a single cement aspect with cement-specific properties (EN 197-1 cement
type, strength class, clinker ratio, constituents with CAS numbers, water-soluble chromium VI under REACH,
EN 15804 indicators per module A1–A3 and C1–C4, end-of-life information).

The semantic model uses the **Semantic Aspect Meta Model (SAMM) 2.1.0** of the Eclipse Semantic Modeling
Framework (https://github.com/eclipse-esmf/esmf-semantic-aspect-meta-model) by reference only.
